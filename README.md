# Mini Booking Travel

Aplikasi web mini berbasis PHP untuk simulasi booking perjalanan.

## Menjalankan aplikasi

1. Letakkan folder proyek di direktori web server lokal, misalnya `C:\xampp\htdocs\travel`.
2. Jalankan Apache dari XAMPP.
3. Buka `http://localhost/travel/` di browser.

## Fitur

- Form nama penumpang, tujuan, dan tanggal booking.
- Nama penumpang dirapikan otomatis saat formulir diproses.
- Waktu pemrosesan dicatat otomatis menggunakan zona waktu Jakarta.
- Pesan tindak lanjut ditentukan berdasarkan jam layanan 08.00–17.00 WIB.
- Validasi tujuan dan tanggal booking, termasuk penolakan tanggal lampau.

Booking hanya ditampilkan sebagai simulasi dan belum disimpan ke database.
